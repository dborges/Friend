Privacy Policy

Last updated: May 2026

1. What We Collect

The App does not collect any personal data from end users. The only data stored is the TikTok OAuth access token and refresh token for the account owner's own account, saved locally on the account owner's device.

2. How We Use Data

OAuth tokens are used exclusively to authenticate API calls to TikTok's Content Posting API on behalf of the account owner. No data is transmitted to third parties beyond what is required by the TikTok API itself.

3. Data Storage

All credentials are stored in a local environment file on the account owner's personal computer. No cloud storage or external databases are used to store user credentials or content data.

4. Third-Party Services

The App uses the TikTok Content Posting API. TikTok's own Privacy Policy applies to all interactions with TikTok's platform.
